强大的功能特性

为现代知识工作者精心设计

📝

所见即所得编辑器

独创的 WYSIWYG Markdown 编辑器，让你在编辑时就能看到格式化效果，同时保持 Markdown 源码的纯粹。

🔍

全文搜索

基于 Tantivy 搜索引擎的全文检索功能，毫秒级响应，快速定位你的任何笔记内容。

🔗

双向链接

使用 [[维基链接]] 语法创建笔记间的关联，自动构建反向链接，发现知识的隐藏联系。

🕸️

知识图谱

可视化展示你的笔记网络，力导向布局让你直观地看到知识之间的关联和结构。

🎨

多主题支持

内置亮色、暗色、高对比三套主题，支持自定义主题，打造舒适的写作环境。

📄

多格式导出

支持导出为 HTML、PDF、DOCX 等多种格式，方便分享和发布你的内容。

📊

幻灯片演示

使用 ## 分隔符创建幻灯片，一键进入全屏演示模式，让你的笔记也能成为演讲素材。

🔄

版本历史

基于 Git 的版本控制，自动保存历史版本，支持差异对比和一键回滚。

💻

代码高亮

基于 Tree-sitter 的语法高亮，支持 Rust、Python、JavaScript、Go、Java 等多种编程语言。
