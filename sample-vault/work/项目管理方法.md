# 项目管理方法

有效的项目管理是确保项目按时、按质、按预算完成的关键。本文介绍几种主流的项目管理方法。

## 敏捷开发

敏捷开发是一种以人为核心、迭代、循序渐进的开发方法。

### Scrum 框架
- **Sprint**：固定长度的迭代周期，通常 2-4 周
- **每日站会**：每天 15 分钟的同步会议
- **待办列表**：产品 Backlog 和 Sprint Backlog
- **角色**：产品负责人、Scrum Master、开发团队

### Kanban 方法
看板方法通过可视化工作流来管理任务进度。
- 可视化工作流
- 限制在制品数量
- 度量流动效率

## 瀑布模型

瀑布模型是传统的线性开发方法，适合需求明确的项目。

阶段：
1. 需求分析
2. 设计
3. 实现
4. 测试
5. 部署
6. 维护

## OKR 目标管理

OKR（Objectives and Key Results）是一种目标设定与管理方法。

```
Objective: 提升产品用户体验
Key Result 1: 用户满意度从 3.5 提升到 4.2
Key Result 2: 用户留存率提升 20%
Key Result 3: 页面加载速度提升 50%
```

## 选择适合的方法

根据 [[项目特性]]、团队规模和组织文化选择合适的方法。很多团队采用混合方法，比如 Scrum + Kanban。

> 没有最好的方法，只有最适合的方法。
