# 神经网络基础

神经网络是深度学习的基础，本文介绍神经网络的基本原理。

## 感知机

感知机是最简单的神经网络单元，由 Rosenblatt 在 1957 年提出。

### 数学表达式
```
y = f(Σ w_i * x_i + b)
```

其中：
- w_i 是权重
- x_i 是输入
- b 是偏置
- f 是激活函数

### 局限
单层感知机只能解决线性可分问题，无法处理异或问题。

## 多层感知机 (MLP)

通过增加隐藏层，MLP 可以解决非线性问题。

### 前向传播
输入从输入层经过隐藏层传递到输出层的过程。

### 反向传播
利用链式法则计算梯度，是训练神经网络的核心算法。

步骤：
1. 前向传播计算损失
2. 反向传播计算梯度
3. 更新权重参数

## 激活函数

### Sigmoid
```
σ(x) = 1 / (1 + e^(-x))
```
- 输出范围 (0, 1)
- 容易出现梯度消失

### ReLU
```
ReLU(x) = max(0, x)
```
- 计算简单
- 缓解梯度消失
- 可能出现神经元死亡

### 为什么需要非线性激活？
如果没有激活函数，多层网络等价于单层网络，无法学习复杂模式。

## 损失函数

### 均方误差 (MSE)
```
MSE = (1/n) * Σ(y_i - ŷ_i)^2
```
常用于回归问题。

### 交叉熵 (Cross-Entropy)
```
H(p, q) = -Σ p(x) * log(q(x))
```
常用于分类问题。

## 优化算法

### 梯度下降
```
θ = θ - α * ∇J(θ)
```

### 随机梯度下降 (SGD)
每次只用一个样本更新梯度，速度快但不稳定。

### Mini-batch SGD
折中方案，每次用一小批样本更新。
