# Assets 目录

此目录用于存放应用程序资源文件，包括：

## 图标文件

请在此目录中放置以下图标文件：

- `icon.png` - 应用程序主图标 (建议尺寸: 256x256)
- `icon.ico` - Windows 系统图标
- `icon.icns` - macOS 系统图标

## 图标说明

1. **icon.png**: 用于 Electron 应用程序的默认图标
2. **icon.ico**: Windows 打包时使用的图标格式
3. **icon.icns**: macOS 打包时使用的图标格式

## 临时说明

在没有实际图标文件的情况下，应用程序会使用系统默认图标。如果需要自定义图标，请将图标文件放置在此目录中。
